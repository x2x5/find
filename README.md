# 实时搜索 AI 顶会论文

> [English Version](#search-ai-conference-papers-in-real-time) · [打开网站](https://example.com)

涵盖 NeurIPS、ICML、ICLR、CVPR、ECCV、ICCV、AAAI、ACM MM 与 IJCAI 等主流顶级会议。

### 核心特性
* **即时检索**：毫秒级呈现结果，点击标题词可直接二次收窄。
* **趋势分析**：会议分布统计与关键词云联动，直观展示研究热点与共现词。
* **快速跳转**：一键直达 arXiv 原文与 GitHub 代码仓库。
* **批量导出**：支持单次一键复制多达 500 篇论文标题。
* **截稿看板**：显示最近顶会截稿倒计时，附带年度九大顶会时间线。
* **双语与暗色**：支持中英文切换、深色模式与移动端自适应。

# Search AI Conference Papers in Real Time

> [中文版](#实时搜索-ai-顶会论文) · [Open Website](https://example.com)

Real-time paper search engine covering NeurIPS, ICML, ICLR, CVPR, ECCV, ICCV, AAAI, ACM MM, and IJCAI.

### Features
* **Instant Search**: Millisecond retrieval; click any title keyword to narrow down results.
* **Trend Analytics**: Dynamic distribution charts and word clouds show topic trends and co-occurrences.
* **Direct Links**: One-click jump to arXiv preprints and GitHub repositories.
* **Batch Export**: Copy up to 500 paper titles simultaneously for analysis.
* **DDL Tracker**: Live countdown to upcoming deadlines with an annual 9-conference timeline.
* **Responsive UI**: Bilingual interface, dark mode, and mobile-friendly design.
